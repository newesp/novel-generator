# 模組 02｜角色系統

**Phase**：1
**Phase**：2　**依賴**：00-book、04-knowledge（Graph 關係層視覺化）

---
## 生成流程

```
用戶點擊'AI 生成角色' → 生成角色
或用戶自行新增/刪除/修改角色
```

---
## 核心功能

- 新增角色
- 刪除角色
- 修改角色
- AI 生成角色（✅ 已實作，含以下強制規則）：
	- 可以設定要生成幾個角色
	- **主線劇情中以名字提及的人物，AI 必然建立角色卡**（不可遺漏，即使只提到一次）
	- 從主線提取的角色排在輸出最前面，**第一個為主角**
	- 若主線提取角色數 < count，補足配角；若超過 count 仍全部輸出
	- **主角的成長弧線必須對應主線劇情各階段**（開頭→中段→高潮→結局）
	- maxTokens = 6144（角色卡欄位多，需較大 token 預算）
- 角色卡片管理
- 關係圖視覺化（D3.js 或 React Flow，資料來源為 04-knowledge Graph JSON）

---
## 角色欄位

| 欄位   | 說明               |
| ---- | ---------------- |
| 姓名   | 角色名稱             |
| 性別   | 男/女/其他           |
| 年齡   | 角色年齡             |
| 種族   | 角色種族             |
| 性格   | MBTI 或描述性文字      |
| 背景   | 出身、經歷            |
| 外貌   | 外型描述             |
| 能力   | 技能、特殊能力          |
| 關係   | 與其他角色的關係，支援多對多連結 |
| 成長弧線 | 角色的成長軌跡          |
- 成長弧線範例：
```
整體弧線：低調自保 → 責任覺醒 → 規則制定者（英雄之旅變體）

階段 1（1-30章）：社畜心態
階段 2（31-80章）：低谷
階段 3（81-150章）：轉折，性格變得更果斷
...
```
