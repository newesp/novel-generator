# 模組 02｜角色系統

**Phase**：1
**Phase**：2　**依賴**：00-book、04-knowledge（Graph 關係層視覺化）

---
## 生成流程

```
用戶點擊'AI 生成角色' → 生成角色
或用戶自行新增/刪除/修改角色
```

---
## 核心功能

- 新增角色
- 刪除角色
- 修改角色
- AI 生成角色：可以設定要生成幾個角色，由 AI 開始生成各角色
- 角色卡片管理
- 關係圖視覺化（D3.js 或 React Flow，資料來源為 04-knowledge Graph JSON）

---
## 角色欄位

| 欄位 | 說明 |
|------|------|
| 姓名 | 角色名稱 |
| 性別 | 男/女/其他 |
| 年齡 | 角色年齡 |
| 種族 | 角色種族 |
| 性格 | MBTI 或描述性文字 |
| 背景 | 出身、經歷 |
| 外貌 | 外型描述 |
| 能力 | 技能、特殊能力 |
| 關係 | 與其他角色的關係，支援多對多連結 |
