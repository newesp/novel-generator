# 模組 01｜大綱生成系統

> Phase / 依賴：見 [README 模組總表](../README.md#模組總表)

## 生成流程

```
題材/風格輸入 → 用戶可點擊「AI 生成世界觀/主線劇情」按鈕 → 生成世界觀設定/主線劇情架構，或用戶自行編輯
```

---

## 輸入欄位

| 欄位            | 說明                    |
| ------------- | --------------------- |
| 題材            | 玄幻/都市/仙俠/科幻/言情/懸疑/自定義 |
| 風格            | 輕鬆/沉重/黑暗/熱血/幽默/爽文/自定義 |
| AI 生成世界觀/主線劇情 | 按鈕，AI 生成世界觀設定/主線劇情架構  |

---

## 輸出可編輯項

- 世界觀設定
- 主線劇情架構

---

## v2 介面

- 大綱使用完整工作區，不與章節編輯器並排。
- 左側 280–320px 為書名、題材、風格、AI 生成與儲存。
- 世界觀與主線劇情使用剩餘空間並排；較窄桌面寬度改為上下排列。
- 長文字只在 textarea 內捲動，仍可使用全螢幕編輯。

## AI 生成按鈕啟用前提

| 條件 | 說明 |
|------|------|
| API 已設定 | LLM endpoint + API Key 均不為空 |
| 題材或風格至少填一項 | 兩者皆空則按鈕 disabled |

API 未設定時，按鈕下方顯示 inline 提示說明。

## AI 生成世界觀/主線劇情

Prompt 使用結構化標記，確保 LLM 的回傳可被可靠解析（不依賴可能出現在正文中的 `===` 分隔符）：

```
##WORLD_START##
（世界觀設定內容）
##WORLD_END##

##PLOT_START##
（主線劇情架構內容）
##PLOT_END##
```

解析時以正則表達式擷取各標記之間的內容，分別填入對應欄位。

## 儲存大綱 UX

- 按鈕顯示「✅ 已儲存」並 disabled，當任意欄位與 DB 中的值不同（isDirty）時才啟用
- 書名在 `onBlur` 時自動儲存；其他大綱欄位以底部儲存按鈕提交
