# 模組 01｜大綱生成系統

**Phase**：1　**依賴**：00-book、02-characters、08-llm-adapter、07-context-budget

---

## 生成流程

```
題材/風格輸入 → 用戶點可選點擊'AI 生成世界觀/主線劇情'按鈕 → 生成世界觀設定/主線劇情架構，或用戶自行編輯 
```

---

## 輸入欄位

| 欄位            | 說明                    |
| ------------- | --------------------- |
| 題材            | 玄幻/都市/仙俠/科幻/言情/懸疑/自定義 |
| 風格            | 輕鬆/沉重/黑暗/熱血/幽默/爽文/自定義 |
| AI 生成世界觀/主線劇情 | 按鈕，AI 生成世界觀設定/主線劇情架構  |

---

## 輸出可編輯項

- 世界觀設定
- 主線劇情架構
