# 模組 05｜章節版本管理

> Phase / 依賴：見 [README 模組總表](../README.md#模組總表)

## 核心概念

每個章節保留最近 3 個生成版本，支援釘選與版本切換，確保用戶不會因重新生成而遺失好的內容。

---

## 版本資料結構

| 欄位 | 型別 | 說明 |
|------|------|------|
| id | string | 版本唯一識別碼（nanoid） |
| chapterId | string | 所屬章節 ID |
| createdAt | number | 生成時間戳（ms） |
| content | string | 正文內容 |
| prompt | string | 生成時使用的提示詞（可供參考，可為空） |
| isPinned | boolean | 是否釘選（釘選版本不受數量上限限制） |
| kind | `'full' \| 'inline'` | 版本來源類型：`full` = 整章生成／手動存入；`inline` = 局部調整（右鍵 → 調整內容）接受時自動建立 |

> **DB 升級相容性**：Dexie schema 升級至 v2 時，舊版本缺少 `kind` 欄位者以 `kind ??= 'full'` 補全。

---

## 運作規則

- 每次重新生成，新版本加入版本列表（最多保留最近 3 個非釘選版本）
- 超過上限時，自動刪除最舊的非釘選版本
- 釘選版本不計入上限，永久保留直到用戶手動解除釘選或刪除
- 用戶可在版本列表中預覽任意版本，並一鍵設為當前使用版本

### 何時自動建立版本

| 時機 | kind |
|------|------|
| 點擊「✨ 生成本章」，且當前有內容 | `full` |
| 點擊「↩️ 重新生成」，且當前有內容 | `full` |
| 點擊「💾 存入版本」 | `full` |
| 右鍵局部調整 → 「✅ 接受寫入」 | `inline` |

---

## UI 設計

```
[版本歷史（N）]
├── ★ v3（當前）        05/08 14:32  [預覽] [釘選]
├──   v2                05/08 13:10  [預覽] [釘選] [刪除]
└── 📌 v1（釘選）局部   05/08 11:05  [預覽] [解除釘選] [刪除]
```

- `★` 標示最新版本（列表第一項，不顯示刪除按鈕）
- `📌` 標示釘選版本
- `局部` 標籤（灰色 badge）顯示於 `kind === 'inline'` 的版本，表示此版本由局部調整產生
- 點擊「預覽」開啟 Modal，可選擇「設為當前」將該版本內容套用至編輯器
