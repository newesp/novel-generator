# 模組 05｜章節版本管理

**Phase**：1　**依賴**：00-book（版本資料透過章節的 bookId 關聯書本）

---

## 核心概念

每個章節保留最近 3 個生成版本，支援釘選與版本切換，確保用戶不會因重新生成而遺失好的內容。

---

## 版本資料結構

| 欄位 | 說明 |
|------|------|
| versionId | 版本唯一識別碼 |
| createdAt | 生成時間戳 |
| content | 正文內容 |
| prompt | 生成時使用的提示詞（可供參考） |
| isPinned | 是否釘選（釘選版本不受 3 個上限限制） |
| label | 用戶自訂標籤（可選，如「最終版」） |

---

## 運作規則

- 每次重新生成，新版本加入版本列表（最多保留最近 3 個非釘選版本）
- 超過上限時，自動刪除最舊的非釘選版本
- 釘選版本不計入 3 個上限，永久保留直到用戶手動解除釘選或刪除
- 用戶可在版本列表中預覽任意版本，並一鍵切換為當前使用版本

---

## UI 設計

```
[第 N 章] ── 版本歷史 ▼
├── ★ v3（當前）  2026-05-08 14:32  [預覽] [釘選]
├──   v2          2026-05-08 13:10  [預覽] [釘選] [設為當前] [刪除]
└── 📌 v1（釘選） 2026-05-08 11:05  [預覽] [設為當前] [解除釘選]
```
