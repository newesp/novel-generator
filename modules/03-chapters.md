# 模組 03｜章節管理器

**Phase**：1　**依賴**：00-book、07-context-budget、04-knowledge、05-versions

---

## 運作流程

```
用戶點擊'AI 生成章節' → 生成章節
或用戶自行新增/刪除/編輯章節

設定標題/目標字數/故事節拍/章節要點 → 用戶點擊'生成' → AI 生成正文
```

---

## 核心功能

- 新增章節
- 刪除章節
- 修改章節
- AI 生成章節
	- 可以設定要生成幾章節，由 AI 開始生成各章節的：標題/參考章節/故事節拍/章節要點

---

## 章節欄位

| 欄位   | 說明                    |
| ---- | --------------------- |
| 標題   | 章節標題                  |
| 目標字數 | 預設空白，可留空讓 AI 自行發揮     |
| 故事節拍 | 引入/衝突/轉折/高潮/結局/自定義    |
| 章節要點 | 給 AI 生成內容用的額外提示詞（可編輯） |
| 正文   | AI 生成的內容（可編輯）         |

---

## 故事節拍機制

| 節拍類型 | 說明 |
|----------|------|
| 引入 (Inciting Incident) | 故事起因，角色面臨轉折點 |
| 衝突升級 (Rising Action) | 矛盾加深，困難加劇 |
| 中點轉折 (Midpoint Twist) | 重大變化，方向逆轉 |
| 高潮 (Climax) | 最高衝突點，決定性時刻 |
| 結局 (Resolution) | 問題解決，塵埃落定 |
| 鋪墊/過渡 | 連接章節的過渡內容 |
| 自定義 | 用戶手動輸入節拍描述 |

**運作方式：**
1. AI 根據上一章或選定章節的內容，建議下一章的故事節拍
2. 用戶可選擇接受建議、選擇預設類型、或手動輸入自定義節拍
3. 生成內容時，故事節拍作為系統提示詞的一環引導 AI

---

## 生成上下文自定義

| 項目         | 說明                            |
| ---------- | ----------------------------- |
| 參考章節選擇     | 不局限於上一章，可選擇任意章節               |
| 參考 Wiki 內容 | 可選擇載入哪些 Wiki 條目               |
| 參考章節要點     | 預設可編輯，用戶自由調整                  |
| 調整方向       | 生成後可輸入修改指令讓 AI 重新生成           |
| 參考深度       | 淺層/標準/深度，控制 Context Budget 策略 |

**預設提示詞模板（可編輯）：**

```
## 背景資訊
[從 Wiki 提取的世界觀設定]
[角色庫中的相關角色]

## 劇情進展
[當前主線/支線進度]
[與第x章的銜接]

## 本章要求
- 故事節拍: [選擇的節拍類型]
- 章節要點: [用戶編輯的章節要點]
- 目標字數: [可留空]

## 第x章內容
[第x章的正文或壓縮摘要（由 Context Budget Manager 決定）]
```


**生成設置面板 UI：**

```
[生成設置面板]
├── 參考章節: [第 N 章 ▼] 或 [自定義]
├── 參考 Wiki: [□ 世界觀 □ 角色庫 □ 劇情線]
├── 章節要點: [編輯] [重置]
├── 故事節拍: [選擇] 或 [自定義輸入]
├── 參考深度: [淺層 / 標準 / 深度]
└── 調整方向: [生成後可輸入]

生成結果展示 → [重新生成] [確認存入]
```
