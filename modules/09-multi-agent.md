# 模組 09｜Multi-Agent 協作引擎

> Phase / 依賴：見 [README 模組總表](../README.md#模組總表)

## 核心概念

使用 Planner、Writer、Critic、Editor 四種專責 Agent 組成協作流水線，提升生成品質。此模組為**選配**，預設不啟用，用戶可在生成設置面板手動開啟。

---

## 四種 Agent 角色

| Agent   | 職責 | 使用模型建議 |
|---------|------|-------------|
| Planner | 章節細綱優化、邏輯梳理、故事節拍細化 | 中大型模型 |
| Writer  | 撰寫初稿 | 大模型（高創意） |
| Critic  | 打分審核（風格、邏輯、一致性、人物、伏筆） | 大模型（嚴謹） |
| Editor  | 針對 Critic 意見進行潤色與優化 | 大模型或專用潤色模型 |

---

## 迭代優化流程

1. Planner 產生優化後的章節細綱
2. Writer 撰寫初稿
3. Critic 給予詳細評分與改進建議（通過門檻：總分 ≥ 85）
4. 若未達標 → Editor 執行針對性重寫 → 回到 Writer 或 Critic
5. 最多迭代 3-4 次（可用戶調整）
6. 最終版進入版本歷史（參見 05-versions）

---

## 使用模式

- **快速模式（預設）**：單 Agent，Writer 直接生成
- **高品質模式**：完整 Multi-Agent 迭代

**UI 位置：** 生成設置面板中新增「生成模式」切換。

---

## 注意事項

- 完整跑一次迭代可能消耗大量 token（一章 10-20 萬 token），建議用戶先確認 API 費用或確保 Ollama 本機資源充足
- 建議先以單一章節測試，確認品質與成本後再批量使用
