# 規格｜主編輯介面佈局

> 視覺規範（色彩、字體、元件）請參見 [specs/ui.md](ui.md)

## 整體佈局

書本開啟後的核心頁面，採雙欄結構：

```
┌──────────────────────────────────────────────────────────┐
│                      頂部工具列                           │ 48px
├────────────┬─────────────────────────────────────────────┤
│            │                                             │
│  左側面板   │              右側編輯區                      │
│  340px     │              flex: 1                        │
│  (可拖曳)  │                                             │
│  ┌──────┐  ├─────────────────────────────────────────────┤
│  │ 分頁  │  │           右側頂部工具列                     │
│  ├──────┤  ├─────────────────────────────────────────────┤
│  │      │  │                                             │
│  │ 內容  │  │              正文編輯區                      │
│  │      │  │                                             │
│  │      │  │                                             │
│  └──────┘  ├─────────────────────────────────────────────┤
│            │              底部動作列                      │
└────────────┴─────────────────────────────────────────────┘
```

- 左右面板中間的分隔線可左右拖曳調整寬度
- 左側面板最小寬度：280px

**間距規範：**
- 頂部工具列高度：48px
- 左側面板預設寬度：340px（最小 280px）
- 右側面板內邊距：24px
- 面板內元素間距：16px

## 左側面板

以分頁（Tab）組織，分頁包含：

**分頁一：大綱設定**（參見 01-outline）
- 書名（文字輸入）
- 題材（文字輸入，點擊出現預設列表供快速選填，或輸入自定義）
- 風格（文字輸入，點擊出現預設列表供快速選填，或輸入自定義）
- [✨ AI 生成世界觀/主線劇情]（主按鈕）
- 世界觀設定（文字編輯區，可直接編輯）
- 主線劇情架構（文字編輯區，可直接編輯）

**分頁二：角色設定**（參見 02-characters）
- [✨ AI 生成角色] / [+ 新增] / [編輯] / [刪除]（按鈕群）
- 角色列表（卡片式，點擊展開詳情）

**分頁三：章節設定**（參見 03-chapters）
- [✨ AI 生成章節] / [+ 新增] / [編輯] / [刪除]（按鈕群）
- 章節列表
  - 未存入 Wiki 的章節顯示 `⚠️` 橘色標記
  - 點擊章節切換右側編輯區內容

**分頁四：Wiki**（參見 04-knowledge）
- Wiki 面板

## 右側頂部工具列

控制本章節的生成參數，所有設定即時儲存：

| 元件 | 類型 | 說明 |
|------|------|------|
| 參考章節 | 下拉選單 | 預設前一章，可選任意章節 |
| 故事節拍 | 文字輸入 | 點擊出現預設列表，或輸入自定義 |
| 目標字數 | 文字輸入 | 可留空 |
| 章節要點 | 按鈕 | 點擊彈出輸入視窗，輸入給 AI 的額外提示詞 |
| 參考 Wiki | 下拉多選 | 從 Wiki 取得列表：□ 世界觀 □ 角色庫 □ 劇情線 |
| 進階設定 | 按鈕 | 點擊展開版本歷史介面（預設隱藏，寬度 260px） |

---

## 右側正文編輯區

- 顯示當前選定章節的正文
- 支援直接手動編輯
- 生成中顯示串流輸出

---

## 底部動作列

| 元件 | 可見時機 | 說明 |
|------|----------|------|
| 調整方向 | 生成完成後才顯示 | 點擊彈出視窗，輸入調整方向後按下 [重新生成] |
| 重新生成 | 常駐 | 重新呼叫 AI 生成，結果存入版本歷史 |
| 存入版本 | 常駐 | 將當前正文明確存為一個版本（05-versions） |
| 生成下一章節 | 常駐 | 儲存當前章節並切換至下一章節生成流程 |
