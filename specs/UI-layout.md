## 整體佈局

書本開啟後的核心頁面，採雙欄結構：

```
┌──────────────────────────────────────────────────────────┐
│                      頂部工具列                           │ 48px
├────────────┬─────────────────────────────────────────────┤
│            │                                             │
│  左側面板   │              右側編輯區                      │
│  340px     │              flex: 1                        │
│  (可拖曳)  │                                             │
│  ┌──────┐  ├─────────────────────────────────────────────┤
│  │ 分頁  │  │           右側頂部工具列                     │
│  ├──────┤  ├─────────────────────────────────────────────┤
│  │      │  │                                             │
│  │ 內容  │  │              正文編輯區                      │
│  │      │  │                                             │
│  │      │  │                                             │
│  └──────┘  ├─────────────────────────────────────────────┤
│            │              底部動作列                      │
└────────────┴─────────────────────────────────────────────┘
```

- 左右面板中間的分隔線可左右拖曳調整寬度
- 左側面板最小寬度：280px

**間距規範：**
- 頂部工具列高度：48px
- 左側面板預設寬度：340px（最小 280px）
- 右側面板內邊距：24px
- 面板內元素間距：16px

## 左側面板

以分頁（Tab）組織，分頁包含：

**分頁一：大綱設定**（參見 01-outline）
- 書名（文字輸入）
- 題材（文字輸入，點擊出現預設列表供快速選填，或輸入自定義）
- 風格（文字輸入，點擊出現預設列表供快速選填，或輸入自定義）
- [✨ AI 生成世界觀/主線劇情]（主按鈕）
- 世界觀設定（文字編輯區，可直接編輯）
- 主線劇情架構（文字編輯區，可直接編輯）

**分頁二：角色設定**（參見 02-characters）
- [✨ AI 生成角色] / [+ 新增] / [編輯] / [刪除]（按鈕群）
- 角色列表（卡片式，點擊展開詳情）

**分頁三：章節設定**（參見 03-chapters）
- [✨ AI 生成章節] / [+ 新增] / [編輯] / [刪除]（按鈕群）
- 章節列表
  - 未存入 Wiki 的章節顯示 `⚠️` 橘色標記
  - 點擊章節切換右側編輯區內容

**分頁四：Wiki**（參見 04-knowledge）
- Wiki 面板

## 頂部工具列（全域）

```
[📖 小說產生器]  [新建專案]  <專案名稱>  ←空白→  [導出]  [⚙️ 偏好設定]
```

「⚙️ 偏好設定」開啟 Modal，採分頁式設定：

1. **🔑 LLM API**：provider、顯示名稱、API 端點（Base URL）、API Key、模型名稱。切換 provider 時會套用該 provider 的預設顯示名稱 / Base URL / 模型，API Key 目前保留單一 active 設定。
2. **🖼 圖片生成**：圖片 provider、尺寸、風格、panel count，以及 ComfyUI / OpenAI-compatible image provider 的 endpoint、model、API key 等設定。
3. **✨ 選取調整**：預設上下文範圍（window / full）、前後字數（window 模式下可編輯）。
4. **📜 AI 提示詞**：章節生成、Wiki ingest、Lint 等 prompt 模板。
5. **📚 Wiki 設定**：context budget、pick-pages、Lint checks 與 LLM 上限。

## 右側頂部工具列

控制本章節的生成參數，所有設定即時儲存：

| 元件 | 類型 | 說明 |
|------|------|------|
| 章節標題 | 文字輸入 | 章節標題，失焦自動儲存 |
| 參考章節 | 下拉選單 | 預設「無」，可選任意其他章節（含無正文的章節） |
| 故事節拍 | 文字輸入 + datalist | 點擊出現預設列表，或輸入自定義 |
| 目標字數 | 數字輸入 | 可留空讓 AI 自行決定 |
| 章節要點 | 按鈕 | 點擊彈出 Modal，輸入對整章的風格/方向提示（傳入生成 prompt） |

---

## 右側正文編輯區

- 顯示當前選定章節的正文
- 支援直接手動編輯，失焦自動儲存
- **右鍵選單**：選取文字後按右鍵，出現「✨ 調整內容」選項（僅在有非空選取時顯示），點擊開啟 AdjustContentModal 進行局部 AI 改寫
- 右側附有版本歷史面板（VersionPanel），常駐顯示

---

## 底部動作列

| 元件 | 說明 |
|------|------|
| 💾 存入版本 | 將當前正文明確存為一個 `full` 版本（05-versions），有內容才啟用 |
| 💾 儲存 | 儲存標題/正文/設定至 DB，成功顯示「✅ 已儲存」1.5 秒 |
| ↩️ 重新生成 | 先將當前內容存版本，再重新呼叫 AI 生成；需有現有內容且 API 已設定 |
| ✨ 生成本章 | 呼叫 AI 生成本章正文；需 API 已設定且世界觀已填寫 |

> **調整方向**按鈕已移除。對整章風格/方向的調整請寫入「章節要點」後重新生成；局部文字修改請使用右鍵「✨ 調整內容」。
