- 側欄展開寬度 188px，收合後 58px。

- 工具列高度 72px。
- 工作區填滿剩餘尺寸，外層不捲動。
- 各頁自行決定清單、文字編輯器或圖庫的局部捲動區。

## 工作區

### 大綱

```text
┌──────────────┬────────────────────┬────────────────────┐
│ 基本設定      │ 世界觀設定          │ 主線劇情架構         │
│ 書名／題材    │                    │                    │
│ 風格／AI 生成 │ textarea           │ textarea           │
│              │                    │                    │
│ 儲存          │                    │                    │
└──────────────┴────────────────────┴────────────────────┘
```

- 基本設定欄約 280–320px。
- 世界觀與主線編輯器平分剩餘寬度。
- 低於 1120px 時，右側兩個編輯器改為上下排列。
- Textarea 內部捲動，保留全螢幕編輯入口。

### 角色

```text
┌────────────────┬─────────────────────────────────────────┐
│ 搜尋／AI／新增  │ 角色標題                    AI填寫  儲存 │
│ 角色清單        ├─────────────────────────────────────────┤
│                │ 基本資料 | 故事設定 | 漫畫視覺           │
│                │                                         │
│                │ inline editor / 關係圖                  │
└────────────────┴─────────────────────────────────────────┘
```

- 左側 master list 固定 320px，支援搜尋、多選刪除、列表／關係圖切換。
- 右側直接編輯角色，不使用長表單 Modal。
- 基本資料、故事設定、漫畫視覺使用 Tabs。
- 漫畫視覺包含外貌、Negative Prompt 與角色參考圖。
- AI 批次生成仍使用 Modal；AI 補欄位使用右側工具列。

### 場景

```text
┌──────────────────────┬────────────────────────────────────┐
│ 章節                  │ 分鏡來源                            │
├──────┬──────────────────────────┬─────────────────────────┤
│ 場景 │ 搜尋／選擇場景             │ 從此格建立場景            │
├─────────────────────────────┬──────────────────────────────┤
│ 場景名稱／提示詞／排除詞       │ 參考圖上傳／圖庫              │
└─────────────────────────────┴──────────────────────────────┘
```

- 不顯示漫畫用的章節／分鏡 rail。
- 場景下拉只顯示目前選擇，支援搜尋與「無場景」。
- 「從此格建立場景」只有選到分鏡時可用，按鈕使用內容寬。
- 場景 label、dropdown、建立按鈕保持同組靠攏。
- 下方只顯示選中場景的設定；文字與參考圖左右分欄。
- 場景提示詞 label 與 textarea 使用 6px 間距，textarea 填滿剩餘高度。

### 章節

- 左側為章節清單、AI 生成、新增、多選與排序。
- 右側為章節標題、正文、版本與動作列。
- 「章節設定」集中管理參考章節、目標字數、章節語氣與章節要點。
- 漫畫入口只保留側欄「漫畫」，章節頁不重複提供「轉漫畫」。

### Wiki

- 使用完整工作區，不嵌在章節編輯器。
- 左側為頁面類型、搜尋與 Wiki 清單；右側為頁面編輯器。
- slug 修改使用有驗證的輸入 Dialog，不使用瀏覽器 `prompt()`。
- 保留 Lint、Graph、問 Wiki、摘要品質、操作記錄等既有流程。

### 漫畫

- 沿用共享 `ComicModal` 邏輯，但以 embedded workspace 顯示。
- 三區為章節／分鏡 rail、選中分鏡編輯器、角色／參考圖／場景工具區。
- 可生成分鏡、生成／上傳圖片、切換歷史圖、下載與編輯提示詞。

### 影片

- 與漫畫共用分鏡、媒體與輸出邏輯，但隱藏漫畫專用 prompt／selector 區。
- 保留旁白、旁白音色、MP4 素材、原聲音量、旁白較長時策略、motion effect、單格與整章輸出、SRT、影片庫。
- Native Edge-TTS / ffmpeg 功能仍是桌面版限定。

## 全域工具列與 Dialog

- 書庫 breadcrumb：返回書庫。
- 專案操作：匯出、備份、偏好設定。
- 偏好設定包含 Interface Language、新書預設創作語言、LLM Profiles、Multi-Agent、圖片生成、選取調整、AI Prompt、Wiki、Lint、影片工具等設定。
- Interface Language 即時切換 UI；新書預設創作語言只預填建立書本表單，不修改既有書籍。
- 需要確認或批次操作的流程使用 Modal；主要資源編輯使用工作區。

## 佈局驗證

- 主要尺寸：1440×900、1024×768。
- `body`、`.v2-workspace` 的 scroll/client 尺寸應一致。
- 固定 sidebar、toolbar 與工作區不得產生雙層 scrollbar。
- 文字、圖庫和清單可局部捲動；按鈕與 Select 不得因 Grid 剩餘空間被拉伸或裁切。
