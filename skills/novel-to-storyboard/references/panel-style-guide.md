# Panel Style Guide

Use one style preset per storyboard unless the user explicitly asks for mixed styles.

## color-webtoon

Use vertical-scroll webtoon style, clean line art, expressive faces, crisp silhouettes, cinematic lighting, saturated but controlled color, readable action poses.

Prompt cue:
`color webtoon style, cinematic comic panel, clean line art, expressive faces, dramatic but readable composition`

## black-white-manga

Use black and white manga style, screentone, sharp ink lines, high contrast, speed lines for action, expressive closeups for emotion.

Prompt cue:
`black and white manga panel, screentone shading, sharp ink linework, high contrast, dynamic composition`

## cinematic-storyboard

Use film storyboard style, camera-first composition, rough but clear value structure, readable blocking, strong shot continuity.

Prompt cue:
`cinematic storyboard frame, clear camera blocking, grayscale sketch, production storyboard, strong composition`

## light-novel-illustration

Use polished anime/light novel illustration style, attractive character rendering, soft lighting, detailed expressions, emotionally clear poses.

Prompt cue:
`light novel illustration style, polished anime rendering, soft cinematic lighting, detailed character expression`

## fantasy-ink

Use dramatic fantasy illustration with ink and painterly color, strong atmosphere, textured environments, heroic silhouettes.

Prompt cue:
`fantasy ink illustration, painterly color, dramatic atmosphere, detailed environment, heroic composition`

## wuxia-ink

Use Chinese ink painting influence, elegant brush texture, restrained color, flowing fabric, mist, mountains, courtyards, cinematic martial arts posture.

Prompt cue:
`wuxia ink painting inspired comic panel, elegant brush texture, misty atmosphere, flowing fabric, cinematic martial arts composition`

## Default Negative Prompt

Use or adapt:
`inconsistent face, wrong character design, extra fingers, extra limbs, distorted hands, unreadable text, speech bubbles with gibberish, low detail, blurry, cropped face, duplicate character, off-model outfit`
