# 每次生成執行建立前確認成本預檢

完整 Multi-Agent 流程可能包含 Planner、Writer、多次 Critic、最多五次可設定 Editor 修訂、一次人工額外修訂及結構化輸出修復，而自訂 provider 又沒有可靠的統一價格來源。因此每次建立生成執行前都顯示最壞呼叫數、預估輸入／輸出 token、各角色的連線設定檔與模型，並要求使用者確認；幣別成本只在對應設定檔由使用者填寫輸入／輸出每百萬 token 單價時顯示。全域偏好設定可關閉 token 計算與顯示，關閉後預檢仍保留呼叫數、模型與付費警告，不自動查詢或維護 provider 價格表。Provider 實際回傳的 token usage 無論顯示設定如何都保存至執行軌跡；開關只控制 App 自行估算、彙總與 UI 呈現。
