# Triage Labels

| 技能中的角色 | GitHub label | 意義 |
|---|---|---|
| `needs-triage` | `needs-triage` | 維護者尚待評估 |
| `needs-info` | `needs-info` | 等待回報者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可由 Agent 執行 |
| `ready-for-human` | `ready-for-human` | 需要人工實作或裁定 |
| `wontfix` | `wontfix` | 不會處理 |

技能提到 canonical triage role 時，使用表中對應的 GitHub label。
